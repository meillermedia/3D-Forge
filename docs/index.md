# 3DForge Modeller 0.8

## 3D meshes made simple

Create and refine 3D objects right on your Mac. Start with a primitive, shape
your model down to individual vertices, edges and faces, then export it for 3D
printing, games or rendering.

3DForge is fast, compact and works entirely offline — no account or internet
connection required.

## Create a scene

- Add boxes, spheres, cylinders, tubes and planes with a live preview
- Select, move, rotate and scale objects with global or local controls
- Enter exact position, scale, rotation and colour values
- Work with multiple objects, and duplicate, delete, undo or redo
- Organise objects in a list: rename, show, hide and lock them
- Use optional grid snapping and navigate with the gizmo

## Shape every detail

- Edit vertices, edges and faces directly
- Move, rotate and scale selected mesh elements
- Extrude, remove, connect, chamfer, subdivide and mirror
- Colour faces, smooth meshes and close holes
- Create with Boolean add and subtract, merge, array, remesh and lattice tools
- Save named selection groups for convenient editing

## See your model clearly

Switch between standard, edge and rendered shading, with environment lighting
to help you inspect your work.

## Import and export

Bring existing models into your workflow or export your finished work:

| Format | Import | Export |
| --- | :---: | :---: |
| 3DForge JSON | Yes | Yes |
| glTF / GLB | Yes | Yes |
| OBJ | Yes | Yes |
| STL | Yes | Yes |
| 3DS | Yes | Yes |

Use the native macOS save dialog to manage your files.

## Built for Mac

3DForge runs locally on your Mac, without an account or an internet connection.
It is open source and built with three.js.
